Edit Data → Google Sheet

Change any cell; the Dashboard tab updates instantly. Push to Google Sheet writes only the changed lines (yellow) back to the sheet, then re-pulls to confirm.

Lines are matched to sheet rows by Site + Department (the original pair, so you can rename). New lines are appended to the sheet. Deleting rows is not pushed — delete those in Google Sheets.

One-time setup (needed for Push)

A web page can't write to Google Sheets by itself, so a tiny Apps Script inside your sheet receives the changes.

  1. Open the sheet → Extensions → Apps Script. Delete everything there and paste the code below. Change TOKEN to your own password.
  2. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Deploy and approve the permissions.
  3. Copy the Web app URL and paste it below, along with the same token.
